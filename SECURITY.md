# Security

Report vulnerabilities privately through GitHub’s **Security → Report a vulnerability**
feature. Include the affected version or commit, the failure and impact, and any
redacted evidence. Keep credentials and personal data out of the report.

The skill can operate on connected accounts. Start in Local only and use scoped
credentials and provider approval gates for any external access. Review the
[permissions guide](references/permissions.md) before granting access. Review
[deployment settings](references/cicd.md) before sharing a signing key or enabling uploads.

Contributions are welcome through fork pull requests. Maintainers review the changes
and approve external workflow runs. Passing CI is required to merge to the default branch.
